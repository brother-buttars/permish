# 2026-07-14

- **Full codebase audit (Fable)** — 4 parallel auditors (server, data-layer/leaks, UX, styling) over ~22.5k LOC; all Critical and top Major findings independently re-verified in code. 5 Critical (unenforced bootstrap password; local DB `close()` data loss; hybrid create id divergence; group sync mutations silently dropped; `pending_changes` CHECK enum mismatch), ~47 Major, ~80 Minor. Consolidated report: [[evidence/reviews/2026-07-14-fable-full-audit]]. Opened TODO-012…TODO-017.
- **Audit fixes: TODO-012…017 all closed** (branch `fix/fable-audit`) —
  - *Server security*: `must_change_password` now enforced by the auth middleware (only setup-credentials/me/logout allowed); bootstrap password random or `ADMIN_BOOTSTRAP_PASSWORD`; auth middleware re-verifies the user row per request (deleted/demoted users lose access immediately); `setup-credentials` requires the current password after first login; `GET /events/:id/submissions` requires event owner/group admin/super; `/groups/join` + `/forgot-password` rate-limited; rate-limit keys use the socket address unless `TRUST_PROXY=true` (compose var added) with map eviction; reset-token logging gated off in production + token purge; emails normalized (trim+lowercase) at register/login/invite; login timing oracle removed; register duplicate race → 409; invite codes 12 hex chars.
  - *Hybrid sync*: create routes accept client UUIDs (validated) so offline-created records keep one identity; shared `sync/replay.ts` used by SyncManager and migration covers groups/group_members/group_invites and throws on unknown collections; `pending_changes` CHECK extended (`delete-permanent`, `reassign`) with local v7 rebuild migration; `events.group_id` flows through local insert/update, sync columns, and migration pull; pull now includes owned-event submissions and reports failures as `error` instead of stamping `last_pull_at`; profile updates queue for sync; hybrid→online switch aborts if pending changes remain.
  - *Local durability*: `close()` awaits a real IndexedDB persist (dead localStorage fallback removed); `pagehide`/`visibilitychange` flush; sql.js WASM bundled via `?url` (no CDN dependency); `stmt.free()` in `finally`.
  - *Parent form*: signatures default to `drawn` — an untouched form no longer validates unsigned; server rejects malformed DOB/signature types with 400; `FormProgress` moved below the sticky header (`top-16`); device-local draft persistence + `beforeunload` guard + ConfirmModal leave prompt (replaces `window.confirm`); prefill no longer marks the form dirty; submit failures scroll the error into view; edit form gained a dirty guard and routes parents back to `/submissions`.
  - *Verification*: server 37/37 (`bun test`, 11 new), frontend 179/179 (Vitest, 10 new), `svelte-check` 0 errors, production build emits bundled WASM, doc/schema drift guards pass, real server boot verified.
- **Audit fixes, wave 2: remaining major UX/a11y/leak findings** (branch `fix/fable-audit-2`, stacked on wave 1) —
  - *Leaks & races*: `usePdfPreview`/`useAttachmentPreview` now revoke stale blob URLs and carry a request token (close-while-loading and rapid re-open no longer orphan PDF-sized blobs); `PdfViewer` destroys pdf.js documents on unmount, reacts to `src` changes, and shows an error + retry instead of "Loading PDF..." forever; success-page PDF URL revoked on navigation; the hand-rolled preview/delete state in `event/[id]/submissions` and `form/[id]` replaced with the composables.
  - *Local-mode attachments*: `attachments.getUrl` may now return a Promise — the local adapter resolves the blob lazily instead of returning `''` (first-time previews used to render the page's own HTML as the "PDF"); downloads await + error-toast.
  - *Error surfacing*: `useAuthRequired` catches `onReady` failures, toasts, and exposes `error` + `retry()`; dashboard/events/groups/submissions/event pages render a retry card instead of a fake empty state.
  - *Deep links*: `useAuthRequired` redirects to `/login?next=…`; login and register honor a validated relative `next` (plus the legacy `permish_return_url`) and forward it across their cross-links — emailed event links and group invites now survive the auth wall.
  - *A11y*: `ListCard` is keyboard-operable (role=button, tabindex, Enter/Space, focus ring) and the groups page now uses it; `Modal` gained a real focus trap + focus restore + `label` prop (shared `utils/focusTrap.ts`, also used to add focus-restore to `ConfirmModal`); `GroupCombobox` and the inline stake combobox are keyboard-selectable with combobox/listbox ARIA (mousedown-only selection was pointer-only); SignaturePad mode toggle has `aria-pressed`/group label, canvas an `aria-label`, date input a real label association; admin role changes (incl. promote-to-super) now confirm via ConfirmModal instead of firing on dropdown change.
- **Audit fixes, wave 3: Minor styling/refactor backlog — audit fully closed** (branch `fix/fable-audit-3`, TODO-018) —
  - *3× rule*: the forbidden segmented-tab override string now lives only in `SegmentedTabs` (molecule gained `onSelect` nav mode, group `label`, `aria-pressed`, `type="button"`); adopted in the `account`/`admin`/`groups/[id]` layouts and SignaturePad's 4-button mode strip. Amber warning boxes on import-event/server-settings/DataModeSection replaced with `AlertBox variant="warning"` (AlertBox gained a children snippet). Raw `<select>`s on groups/create and group invites replaced with the `Select` atom. Dashboard "My Submissions" and `event/[id]/submissions` now render through `SubmissionListView` (organism gained `showAge`/`showEmergencyPhone` flags); the event submissions page is composed from `PageHeader` + `FilterPanel` + the organism. `FormField` adopted for all 22 inlined label+input+error triplets.
  - *SignaturePad*: canvas re-blits from the last exported drawing on container resize (ResizeObserver) and the drawing survives switching modes away from Draw and back (previously wiped).
  - *A11y/mobile*: mobile submission-row buttons h-9/gap-2 (were 28px next to Delete); the mobile nav Sheet closes on Escape, traps and restores focus, and carries `role="dialog"`/aria-modal/label (mirrors Modal).
  - *Copy*: group-detail audit-log tab renamed "Activity" → "History" (no longer collides with Activities=events); invite page dates via `formatDate()` and error copy mapped to real sentences instead of splicing server codes; anonymous success page no longer claims logging in will reveal the submitted PDF.
  - *Verification*: frontend 183/183 (4 new SegmentedTabs tests), `svelte-check` 0 errors across 795 files, production build passes, doc-drift guard passes.
