All persistent data in Permish lives in Docker volumes. This page covers how to back up and restore each one.

## Docker Volumes

| Volume            | Contents                             | Container path |
|-------------------|--------------------------------------|----------------|
| `db-data`         | SQLite database (`permish.sqlite`)   | `/app/data`    |
| `pdf-storage`     | Generated PDF files                  | `/app/pdfs`    |
| `uploads-storage` | Uploaded event attachments           | `/app/uploads` |
| `caddy_data`      | TLS certificates (production)        | —              |
| `caddy_config`    | Caddy configuration state (production)| —             |

## Manual Backup

### Database

Copy the SQLite database out of the `server` container:

```bash
docker compose cp server:/app/data/permish.sqlite ./backup-permish.sqlite
```

### Uploads and PDFs

Back up uploaded attachments and generated PDFs:

```bash
docker compose cp server:/app/uploads ./backup-uploads
docker compose cp server:/app/pdfs ./backup-pdfs
```

### TLS Certificates

If you use the `production` profile, back up the Caddy certificate volume:

```bash
docker run --rm -v permissionform_caddy_data:/data -v $(pwd):/backup \
  alpine tar czf /backup/caddy-data-backup.tar.gz /data
```

## Automated Daily Backup (Cron)

Add to your crontab with `crontab -e`:

```bash
# Back up the SQLite database every day at 3:00 AM
0 3 * * * docker compose -f /path/to/docker-compose.yml \
  cp server:/app/data/permish.sqlite /backups/permish-$(date +\%F).sqlite
```

To keep only the last 30 days of backups:

```bash
# Clean up backups older than 30 days
0 4 * * * find /backups -name "permish-*.sqlite" -mtime +30 -delete
```

:::tip[Hot Backups]
SQLite uses WAL (Write-Ahead Logging) mode. You can safely copy the `.sqlite` file while the application is running without stopping services.
:::

## In-App Encrypted Backup

Permish supports encrypted backup files (`.permish-backup`) that use AES-256 encryption.

### Export

From the account settings page, select **Export Data**. Choose a password and download the encrypted backup file.

### Restore

From the account settings page, select **Import Data**. Upload the `.permish-backup` file and enter the password used during export. Data is decrypted and restored into the current instance.

Backup files are portable. Export from one instance and restore on another.

## SQLite File Location

When running without Docker, the SQLite database defaults to:

```
server/data/permish.sqlite
```

The `DB_PATH` environment variable controls this path. Inside Docker, it maps to `/app/data/permish.sqlite`.
