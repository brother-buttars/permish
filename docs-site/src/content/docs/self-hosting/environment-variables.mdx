Copy the example file and edit it with your values:

```bash
cp .env.example .env
```

These variables configure the Bun + Hono server (see `server/src/config.ts`) plus the frontend build.

## Required

| Variable     | Description                       |
|--------------|-----------------------------------|
| `JWT_SECRET` | Secret key for signing JWT tokens. Use a long, random string. |

:::caution
Always set a strong, unique `JWT_SECRET` in production. If it is left at the default value, the server refuses to start in production.
:::

## Server (Core)

| Variable              | Default                    | Description                                   |
|-----------------------|----------------------------|-----------------------------------------------|
| `PORT`                | `3001`                     | Port the server listens on                    |
| `JWT_SECRET`          | *(required)*               | Secret key for signing JWT tokens             |
| `JWT_EXPIRY_SECONDS`  | `86400`                    | JWT lifetime in seconds (24 h)                |
| `FRONTEND_URL`        | `http://localhost:3000`    | Public URL of the frontend                    |
| `DB_PATH`             | `./data/permish.sqlite`    | Path to the SQLite database file              |
| `PDF_DIR`             | `./pdfs`                   | Directory for generated PDFs                  |
| `UPLOADS_DIR`         | `./uploads`                | Directory for uploaded event attachments      |
| `CORS_ORIGINS`        | —                          | Comma-separated list of allowed CORS origins  |

## Email (Optional)

Required only if you want to send form links and notifications via email. SMS is delivered through carrier email gateways using these same settings.

| Variable              | Default            | Description                                          |
|-----------------------|--------------------|-----------------------------------------------------|
| `EMAIL_PROVIDER`      | `gmail`            | Email provider (`gmail`, Resend-ready)              |
| `SMTP_HOST`           | `smtp.gmail.com`   | SMTP server hostname                                |
| `SMTP_PORT`           | `587`              | SMTP server port                                    |
| `SMTP_USER`           | —                  | SMTP username                                       |
| `SMTP_PASS`           | —                  | SMTP password or app-specific password              |
| `RESEND_API_KEY`      | —                  | API key when using Resend instead of SMTP           |
| `EMAIL_FROM_NAME`     | `Permish`          | Display name on outgoing email                      |
| `EMAIL_FROM_ADDRESS`  | —                  | Sender email address                                |

:::tip[Gmail]
Use a [Gmail App Password](https://myaccount.google.com/apppasswords), not your account password. Go to Google Account > Security > App passwords.
:::

## Build-Time Variables

This is baked into the SvelteKit build. Set it at build time or pass it as a Docker build arg.

| Variable             | Default                   | Description                                             |
|----------------------|---------------------------|---------------------------------------------------------|
| `PUBLIC_API_URL`     | `http://localhost:3001`   | Server URL the browser calls. Falls back to the current origin, or a user-set `permish_server_url` in localStorage. |

## HTTPS / Production

| Variable | Default     | Description                              |
|----------|-------------|------------------------------------------|
| `DOMAIN` | `localhost` | Your domain name. Setting this enables Caddy HTTPS via the `production` profile. |
