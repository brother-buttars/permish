Run Permish locally without Docker for development. This gives you hot module replacement and fast iteration.

## Prerequisites

| Tool    | Version | Install                                      |
|---------|---------|----------------------------------------------|
| Bun     | latest  | [bun.sh](https://bun.sh) — runs the server   |
| Node.js | 24 LTS  | `nvm install` (reads `.nvmrc` automatically) |
| pnpm    | 10+     | `corepack enable && corepack prepare pnpm@latest --activate` |
| nvm     | any     | [github.com/nvm-sh/nvm](https://github.com/nvm-sh/nvm) |

## Clone and Install

```bash
git clone https://github.com/brother-buttars/permish.git
cd permish
```

Set up the environment file:

```bash
cp .env.example .env
# Edit .env with your JWT_SECRET and optional email settings
```

Install dependencies. The server uses Bun; the frontend uses pnpm:

```bash
cd server && bun install
cd ../frontend && pnpm install
```

## Start Development Servers

Open two terminals:

**Terminal 1 — Server:**

```bash
cd server
bun run dev
```

Starts the Bun + Hono API server on port 3001 in watch mode for auto-reload.

**Terminal 2 — Frontend:**

```bash
cd frontend
pnpm dev
```

Starts the SvelteKit dev server on port 3000 with hot module replacement.

| Service  | URL                    |
|----------|------------------------|
| Frontend | http://localhost:3000   |
| Server   | http://localhost:3001   |

The browser talks to the server directly using `PUBLIC_API_URL` (default `http://localhost:3001`).

:::caution
HTTP mode does not set secure cookies and does not test CORS or mixed-content behavior. Use [HTTPS development mode](/permish/development/https-dev/) to catch production issues early.
:::

## Project Structure

```
permish/
├── server/                Bun + Hono + SQLite server (the only backend)
│   ├── src/
│   │   ├── index.ts       HTTP entry (export default { port, fetch })
│   │   ├── app.ts         Hono app factory (createApp(db)) — testable
│   │   ├── config.ts      Environment config
│   │   ├── db.ts          bun:sqlite schema + super-admin bootstrap
│   │   ├── lib/           Auth (JWT cookie), validate, rate limiting
│   │   ├── routes/        API route handlers
│   │   ├── services/      Email, SMS, PDF generation, invites, audit
│   │   └── templates/     Church PDF template
│   └── test/              bun test suites (in-process via app.request)
├── frontend/              SvelteKit app (Svelte 5, Tailwind v4)
│   ├── src/
│   │   ├── app.css        Theme (oklch colors, dark mode)
│   │   ├── lib/
│   │   │   ├── data/          Repository pattern (adapters, sync, backup)
│   │   │   ├── stores/        Svelte stores (auth, toast)
│   │   │   ├── components/    UI components (shadcn-style)
│   │   │   └── utils/         Shared utilities
│   │   └── routes/            SvelteKit pages
│   └── src-tauri/             Tauri v2 desktop/mobile config
├── shared/                Single source of truth for the data schema
├── scripts/               Utility scripts
├── docker-compose.yml     Production Docker setup
├── Caddyfile              Production Caddy config
├── Caddyfile.dev          Local HTTPS Caddy config
└── dev.sh                 Local HTTPS startup script
```

## Key Files

| File | Purpose |
|------|---------|
| `server/src/index.ts` | HTTP entry point (`export default { port, fetch }`). |
| `server/src/app.ts` | Hono app factory (`createApp(db)`). Route mounting order matters (form routes before event routes). |
| `server/src/db.ts` | `bun:sqlite` schema and super-admin bootstrap. |
| `frontend/src/lib/data/` | Repository pattern layer (HTTP, local, and hybrid adapters). |
| `frontend/src/app.css` | Theme variables (oklch colors, dark mode). |
| `frontend/src/lib/components/ui/` | shadcn-style base components. |
