Permish has two test suites: the server (`bun test`) and the frontend (Vitest).

## Test Summary

| Suite    | Framework | Command                       |
|----------|-----------|-------------------------------|
| Server   | bun test  | `cd server && bun test`       |
| Frontend | Vitest    | `cd frontend && pnpm test`    |

## Server Tests

```bash
cd server
bun test
```

- **Framework:** `bun test`
- **Harness:** Each suite builds the Hono app in-process with `createApp(createDb(':memory:'))` and drives it via `app.request()` — no network or ports involved.
- **Database:** In-memory SQLite (`:memory:`) — no test data persists between runs
- **Rate limiting:** Disabled when `NODE_ENV=test`
- **Coverage areas:** Auth, events, forms, submissions, profiles, PDF generation, and a schema guard test that fails if the generated DDL drifts from `shared/schema.ts`

## Frontend Tests

```bash
cd frontend
pnpm test
```

- **Framework:** Vitest
- **Coverage areas:** Components, utilities, stores, API client, form validation

### Watch Mode

Re-runs tests on file changes:

```bash
cd frontend
pnpm test:watch
```

## Running All Tests

Run both suites in sequence:

```bash
cd server && bun test && cd ../frontend && pnpm test
```

## Writing Tests

### Server

Tests live in `server/test/`. Each test file builds the Hono app in-process and drives it with `app.request()` against an in-memory database:

```typescript
import { test, expect, beforeAll } from 'bun:test';
import { createDb, bootstrapSuperAdmin } from '../src/db.ts';
import { createApp } from '../src/app.ts';

let app: ReturnType<typeof createApp>;

beforeAll(() => {
  const db = createDb(':memory:');
  bootstrapSuperAdmin(db);
  app = createApp(db);
});

test('GET /api/events returns events for an authenticated planner', async () => {
  const res = await app.request('/api/events', { headers: { Cookie: authCookie } });
  expect(res.status).toBe(200);
});
```

### Frontend

Tests live alongside components or in `frontend/src/lib/`. Vitest provides a fast test runner with Vite's module resolution:

```typescript
import { describe, it, expect } from 'vitest';
import { formatDate } from './formatDate';

describe('formatDate', () => {
  it('formats date-only values', () => {
    expect(formatDate('2026-03-20')).toBe('20 March 2026');
  });
});
```
